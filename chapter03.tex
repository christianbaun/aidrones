\renewcommand{\deutschertitel}{Fernsteuerung Firmware: EdgeTX}
\renewcommand{\englischertitel}{Remote Control Firmware: EdgeTX}
\makroabschnitt
\label{AbschnittEdgeTX}

EdgeTX is an operating system for radio transmitters used in model aircraft and drones. It is open-source software and runs on transmitters from many well-known manufacturers. EdgeTX generates the control signals, which are then transmitted by the ExpressLRS firmware (see Section~\ref{AbschnittExpressLRS}) running on the transmitter module.

\colger

EdgeTX ist ein Betriebssystem für Fernsteuerungen im Modellbau. Es handelt sich um freie Software, die auf Fernsteuerungen vieler bekannter Hersteller läuft. EdgeTX erzeugt die Steuersignale, welche anschließend von der Firmware ExpressLRS (siehe Abschnitt~\ref{AbschnittExpressLRS}) des Sendemoduls übertragen werden.

\coleng

Installation is performed via the web application \url{buddy.edgetx.org}. This section describes the installation process on a Radiomaster Boxer using a PC. The same approach also works with the Radiomaster Pocket, TX12, and older versions of the TX16S.

\colger

Die Installation erfolgt über die Webanwendung \url{buddy.edgetx.org}. Dieser Abschnitt beschreibt die Installation auf einer Radiomaster Boxer mithilfe eines PCs. Auf die gleiche Art und Weise funktioniert es auch bei den Modellen Radiomaster Pocket, TX12, und bei älteren TX16S.


\coleng

\colger

Die Fernsteuerung wird im ausgeschalteten Zustand über die obere USB-C-Schnittstelle mit dem PC verbunden. In der Webanwendung wird die gewünschte Version sowie das passende Gerät ausgewählt (siehe Abbildung~\ref{AbbildungEdgeTXInstallation1}). Die Schaltfläche \textsl{Flash via USB} führt zum nächsten Schritt.

\renewcommand{\deutschertitel}{DFU-Modus bei unterschiedlichen Fernsteuerungen}
\renewcommand{\englischertitel}{DFU Mode of Different Remote Controls}
\makrounterabschnitt
\label{AbschnittAndereFernsteuerungen}

The method for putting individual radio transmitters into DFU (Device Firmware Update) mode, so that they are recognized as an STM32 BOOTLOADER (see Figure~\ref{AbbildungEdgeTXInstallation2}), varies across different manufacturers and their respective models.

\colger

Die Art und Weise, wie einzelne Fernsteuerungen in den DFU-Modus (Device Firmware Update) gebracht werden, um als STM32 BOOTLOADER (siehe Abbildung~\ref{AbbildungEdgeTXInstallation2}) erkannt zu werden, ist bei vielen Herstellern und deren Modellen unterschiedlich umgesetzt.

\coleng

For example, the Radiomaster GX12 has only a single USB port. To put the transmitter into DFU mode in order to install EdgeTX, the following steps must be performed: With the transmitter powered off, it must be connected to the PC using a USB cable. Then, the SG switch and the power button must be pressed simultaneously. From that moment on, the transmitter is recognized as an STM32 BOOTLOADER.

\colger

Eine Radiomaster GX12 verfügt beispielsweise nur über einen USB-Anschluss. Um die Fernsteuerung in den DFU-Modus zu versetzen, um EdgeTX zu installieren, müssen folgende Schritte ausgeführt werden: Im ausgeschalteten Zustand muss die Fernsteuerung mit einem USB-Kabel mit dem PC verbunden werden. Anschließend müssen der Schalter SG und die Einschalttaste gleichzeitig gedrückt werden. Ab diesem Zeitpunkt wird die Fernsteuerung als STM32 BOOTLOADER erkannt.

\coleng

An overview of different radio transmitter manufacturers and their models can be found on the following website:

\colger

Eine Übersicht über verschiedene Hersteller von Fernsteuerungen und deren Modelle bietet die folgende Webseite:

\colende

\href{https://manual.edgetx.org/edgetx-how-to/access-dfu-and-bootloader-mode}{https://manual.edgetx.org/edgetx-how-to/access-dfu-and-bootloader-mode}


\renewcommand{\deutschertitel}{Sendemodul- und Empfänger-Firmware: ExpressLRS}
\renewcommand{\englischertitel}{Transmitter and Receiver Firmware: ExpressLRS}
\makroabschnitt
\label{AbschnittExpressLRS}

The firmware of the transmitter module in the remote control and the receiver in the drone must both use compatible firmware versions. Ideally, the firmware versions of the transmitter and receiver are identical. This section focuses exclusively on the ExpressLRS firmware, including its installation and configuration.

\colger

Die Firmware des Sendemoduls in der Fernsteuerung und des Empfängers in der Drohne müssen beide mit kompatibler Firmware ausgestattet sein. Idealerweise sind bei Sender und Empfänger die Versionen identisch. Dieser Abschnitt befasst sich ausschließlich mit der Firmware ExpressLRS sowie deren Installation und Konfiguration.

\coleng

Installation is performed using the locally installed application ExpressLRS Configurator. Installation packages and the source code can be found here:

\colger

Die Installation erfolgt über die lokal installierte Anwendung ExpressLRS Configurator. Installationspakete und der Quellcode befinden sich hier:

\colende

\smallskip
\url{https://github.com/ExpressLRS/ExpressLRS-Configurator/releases}
\smallskip

\colstart

In the ExpressLRS Configurator, the desired version, device type, connection method (EdgeTX Passthrough, UART, or Wi-Fi), frequency band usage permissions (Listen Before Talk), and the binding phrase are defined. The binding phrase must match the one later used on the receiver (see Figure~\ref{AbbildungExpressLRS1}).

\colger

Im ExpressLRS Configurator werden die gewünschte Version, das Gerät, die Zugriffsart (EdgeTX Passthrough, UART oder Wi-Fi), die erlaubte Nutzung des Frequenzbands (Listen Before Talk) sowie die Binding Phrase festgelegt. Diese muss mit der später beim Empfänger verwendeten Binding Phrase übereinstimmen (siehe Abbildung~\ref{AbbildungExpressLRS1}).

ESP-based ExpressLRS (ELRS) transmitter modules typically include a TX Backpack, which is a WiFi-capable microcontroller. The TX Backpack enables communication with external devices such as a ground station. As described in a later section, this functionality can be used to establish a wireless communication link for controlling the drone directly from the ground station.

\colger

ESP-basierte ExpressLRS-Sendemodule (ELRS) verfügen üblicherweise über einen TX Backpack. Dabei handelt es sich um einen WLAN-fähigen Mikrocontroller. Der TX Backpack ermöglicht die Kommunikation mit externen Geräten wie einer Bodenstation. Wie in einem späteren Abschnitt beschrieben, kann diese Funktion genutzt werden, um eine drahtlose Kommunikationsverbindung zur direkten Steuerung der Drohne von der Bodenstation aus herzustellen.

\coleng

The TX Backpack firmware can be installed using several methods, the simplest of which is via WiFi. Although installation via WiFi requires the device to already contain a functional version of the Backpack firmware, nearly all Backpack-capable devices are shipped with the firmware preinstalled. Therefore, this guide focuses on installation via WiFi.

\colger

Die TX-Backpack-Firmware kann auf verschiedene Arten installiert werden. Die einfachste Methode ist die Installation über WLAN. Obwohl hierfür bereits eine funktionsfähige Version der Backpack-Firmware auf dem Gerät vorhanden sein muss, werden nahezu alle Backpack-fähigen Geräte mit vorinstallierter Firmware ausgeliefert. Daher konzentriert sich diese Anleitung auf die Installation über WLAN.

The installation process for the TX Backpack firmware is similar to the firmware installation procedures described in the previous sections. First, the Backpack firmware must be generated using the ExpressLRS Configurator by selecting the appropriate transmitter target. WiFi must be selected as the flashing method (see Figure~\ref{AbbildungExpressLRSTXBackpack1}).

\colger

Die Installation der TX-Backpack-Firmware erfolgt ähnlich wie die in den vorherigen Abschnitten beschriebenen Firmware-Installationen. Zunächst muss die Backpack-Firmware mit dem ExpressLRS Configurator erzeugt werden. Dazu ist das passende Zielgerät für das Sendemodul auszuwählen. Als Übertragungsmethode muss WiFi ausgewählt werden (siehe Abbildung~\ref{AbbildungExpressLRSTXBackpack1}).

\coleng

During firmware generation, the credentials for a home WiFi network can be specified in the Network section by entering the WiFi SSID and password. These credentials can also be configured after installation. If the credentials are configured and the network is available when the device starts, the TX Backpack automatically connects to it. Other devices connected to the same local network, such as a laptop or mobile device, can then communicate directly with the Backpack.

\colger

Während der Firmware-Erzeugung können im Bereich Network die Zugangsdaten eines WLAN-Heimnetzes angegeben werden. Dazu sind die SSID und das Passwort des WLANs einzutragen. Diese Zugangsdaten können auch nach der Installation konfiguriert werden. Sind die Zugangsdaten hinterlegt und ist das Netzwerk beim Start des Geräts verfügbar, verbindet sich der TX Backpack automatisch damit. Andere Geräte im selben lokalen Netzwerk, beispielsweise ein Laptop oder ein Mobilgerät, können anschließend direkt mit dem Backpack kommunizieren.

\coleng

If the home network is unavailable or no network credentials have been configured, the TX Backpack automatically creates its own wireless access point named \verb!ExpressLRS TX Backpack XXXXXX! with the password \verb!expresslrs!. In this case, external devices must connect to this access point to communicate with the Backpack.

\colger

Wenn das Heimnetzwerk nicht verfügbar ist oder keine Netzwerkzugangsdaten konfiguriert wurden, erstellt der TX Backpack automatisch einen eigenen WLAN-Zugangspunkt mit dem Namen \verb!ExpressLRS TX Backpack XXXXXX! und dem Passwort \verb!expresslrs!. In diesem Fall müssen sich externe Geräte mit diesem Zugangspunkt verbinden, um mit dem Backpack zu kommunizieren.

\coleng

After generating the firmware, WiFi must be enabled for the Backpack on the transmitter. This can be done in the ExpressLRS Lua script by selecting WiFi Connectivity $\rightarrow$ Enable Backpack WiFi.

\colger

Nach der Erzeugung der Firmware muss das WLAN des Backpacks am Sender aktiviert werden. Dies erfolgt im ExpressLRS-Lua-Skript über WiFi Connectivity $\rightarrow$ Enable Backpack WiFi.

\coleng

Once the Backpack is connected, its web interface can be accessed using a web browser. If the Backpack is operating as a wireless access point, the interface is available at \verb!http://10.0.0.1/!. When connected to a home WiFi network, it can instead be accessed at \verb!http://elrs_txbp.local/!. The web interface provides a simple way to upload and install the generated Backpack firmware (see Figure~\ref{AbbildungExpressLRSTXBackpack2}).

\colger

Sobald eine Verbindung zum Backpack besteht, kann dessen Weboberfläche mit einem Webbrowser aufgerufen werden. Wenn der Backpack als WLAN-Zugangspunkt arbeitet, ist die Weboberfläche unter \verb!http://10.0.0.1/! erreichbar. Ist der Backpack mit einem WLAN-Heimnetz verbunden, kann sie stattdessen unter \verb!http://elrs_txbp.local/! aufgerufen werden. Über die Weboberfläche lässt sich die erzeugte Backpack-Firmware einfach hochladen und installieren (siehe Abbildung~\ref{AbbildungExpressLRSTXBackpack2}).

\renewcommand{\deutschertitel}{ExpressLRS: MAVLink-Telemetrie über ExpressLRS}
\renewcommand{\englischertitel}{ExpressLRS: MAVLink Telemetry over ExpressLRS}
\makroabschnitt
\label{AbschnittExpressLRSMavlink}

Starting with ExpressLRS (ELRS) version 3.5, MAVLink can be used to transmit telemetry data from an unmanned aerial vehicle (UAV) to ground-station devices such as laptops and tablets in real time. These telemetry streams may include parameters such as battery voltage, GPS coordinates, altitude, airspeed, ground speed, and other relevant flight-status information. Detailed instructions for configuring MAVLink telemetry with ExpressLRS are available here:

\colger

Seit ExpressLRS (ELRS) Version 3.5 kann MAVLink verwendet werden, um Telemetriedaten eines unbemannten Luftfahrzeugs (Unmanned Aerial Vehicle, UAV) in Echtzeit an Geräte der Bodenstation wie Laptops und Tablets zu übertragen. Diese Telemetriedaten können unter anderem die Batteriespannung, GPS-Koordinaten, Flughöhe, Fluggeschwindigkeit über Grund oder relativ zur umgebenden Luft sowie weitere relevante Informationen zum Flugzustand enthalten. Eine ausführliche Anleitung zur Konfiguration der MAVLink-Telemetrie mit ExpressLRS ist hier verfügbar:

\colende

\smallskip
\url{https://www.expresslrs.org/software/mavlink/}
\smallskip

\colstart

Among flight-controller firmware, ArduPilot provides full support for MAVLink telemetry. Betaflight also supports MAVLink telemetry, whereas INAV currently provides only partial support. This guide focuses on configuration with ArduPilot. Instructions for Betaflight are available here:

\colger

Von den Flugcontroller-Firmwares bietet ArduPilot eine vollständige Unterstützung für MAVLink-Telemetrie. Betaflight unterstützt ebenfalls MAVLink-Telemetrie, während INAV derzeit nur eine teilweise Unterstützung bietet. Diese Anleitung konzentriert sich auf die Konfiguration mit ArduPilot. Eine Anleitung für Betaflight ist hier verfügbar:

\colende

\smallskip
\url{https://betaflight.com/docs/wiki/guides/current/MAVLinkELRS}
\smallskip

\colstart

When MAVLink telemetry is transmitted, the communication link carries both radio-control (RC) commands and telemetry data. To support this dual-purpose communication, ELRS allocates approximately 50% of the available link bandwidth to telemetry transmission, corresponding to a telemetry ratio of 1:2.

\colger

Bei der Übertragung von MAVLink-Telemetrie überträgt die Kommunikationsverbindung sowohl Fernsteuerbefehle (Radio Control, RC) als auch Telemetriedaten. Um diese Doppelnutzung zu ermöglichen, reserviert ELRS ungefähr 50% der verfügbaren Bandbreite für die Übertragung der Telemetriedaten. Dies entspricht einem Telemetrieverhältnis von 1:2.

\coleng

Communication between the ELRS transmitter module (TX) and the ground station can be established either through a USB connection or via WiFi. USB connectivity is available only on external transmitter modules, whereas WiFi connectivity is supported by both internal and external transmitter modules.

\colger

Die Kommunikation zwischen dem ELRS-Sendemodul (TX) und der Bodenstation kann entweder über eine USB-Verbindung oder über WLAN erfolgen. Eine USB-Verbindung ist nur bei externen Sendemodulen möglich, während sowohl interne als auch externe Sendemodule die Kommunikation über WLAN unterstützen.

\colende


\begin{figure}[htb!]
	\centering
	\includegraphics[width=\linewidth]{ELRS_Mavlink_telemetry.png}
	\caption{Reception of MAVLink Telemetry via ExpressLRS at the Ground Station}
	\label{AbbildungExpressLRSMavlinkTelemetryReception}
\end{figure}
\FloatBarrier

\colstart

Most ELRS transmitter modules include an additional WiFi-capable microcontroller commonly referred to as the TX Backpack. This component receives telemetry data from the ELRS system and forwards it to devices at the ground station via a WiFi network.

\colger

Die meisten ELRS-Sendemodule verfügen über einen zusätzlichen WLAN-fähigen Mikrocontroller, der üblicherweise als TX Backpack bezeichnet wird. Diese Komponente empfängt die Telemetriedaten des ELRS-Systems und leitet sie über ein WLAN an die Geräte der Bodenstation weiter.

\coleng

Reliable operation requires sufficient link bandwidth to carry both RC commands and telemetry data without causing unacceptable latency in the control channel. For this reason, the 2.4,GHz frequency band is generally recommended because it provides a higher data rate than lower-frequency alternatives. If greater range or improved link robustness is also required, a dual-band system is recommended.

\colger

Für einen zuverlässigen Betrieb muss eine ausreichende Verbindungsbandbreite zur Verfügung stehen, damit sowohl die Fernsteuerbefehle als auch die Telemetriedaten übertragen werden können, ohne eine unzulässige Verzögerung im Steuerkanal zu verursachen. Daher wird grundsätzlich das 2,4-GHz-Frequenzband empfohlen, da es eine höhere Datenrate als niedrigere Frequenzbänder bietet. Wenn zusätzlich eine größere Reichweite oder eine höhere Robustheit der Funkverbindung erforderlich ist, empfiehlt sich ein Dualband-System.

\colende

\renewcommand{\deutschertitel}{Voraussetzungen für die Unterstützung von MAVLink-Telemetrie in ExpressLRS}
\renewcommand{\englischertitel}{Requirements for MAVLink Telemetry Support in ExpressLRS}
\makrounterabschnitt
\label{AbschnittExpressLRSMavlinkAnforderungen}


\begin{itemize}
\item \texttt{ExpressLRS version 3.5 or later on both the TX and RX modules} - If this requirement is not met, refer to Section~\ref{AbschnittExpressLRS} for instructions on updating ExpressLRS on the transmitter and receiver.
\end{itemize}

\colger

\begin{itemize}
\item \texttt{ExpressLRS Version 3.5 oder neuer auf dem TX- und dem RX-Modul} - Wenn diese Voraussetzung nicht erfüllt ist, finden Sie in Abschnitt~\ref{AbschnittExpressLRS} eine Anleitung zur Aktualisierung von ExpressLRS auf dem Sender und dem Empfänger.
\end{itemize}

\renewcommand{\deutschertitel}{Konfiguration von ELRS-Sender, ELRS-Empfänger und TX Backpack für MAVLink-Telemetrie über WLAN}
\renewcommand{\englischertitel}{Configuring the ELRS TX, RX, and TX Backpack for MAVLink Telemetry via WiFi}
\makrounterabschnitt
\label{AbschnittExpressLRSMavlinkTXRXKonfiguration}

First, the radio transmitter (TX) must be connected to the receiver (RX) installed on the UAV.

\colger

Zunächst muss der Funksender (TX) mit dem im unbemannten Luftfahrzeug (UAV) installierten Empfänger (RX) verbunden werden.

\coleng

\texttt{Change the receiver serial protocol to MAVLink} - On the radio transmitter (TX), open the ExpressLRS Lua script and select Other Devices $\longrightarrow$ the appropriate receiver $\longrightarrow$ Serial Protocol $\longrightarrow$ MAVLink. After completing the configuration, power-cycle the receiver. This step is no longer required starting with ExpressLRS version 4, which supports automatic configuration.

\colger

\texttt{Serielles Protokoll des Empfängers auf MAVLink umstellen} - Öffnen Sie auf dem Funksender (TX) das ExpressLRS-Lua-Skript und wählen Sie Other Devices $\longrightarrow$ den entsprechenden Empfänger $\longrightarrow$ Serial Protocol $\longrightarrow$ MAVLink. Schalten Sie den Empfänger nach Abschluss der Konfiguration aus und wieder ein. Ab ExpressLRS Version 4 ist dieser Schritt nicht mehr erforderlich, da diese Version eine automatische Konfiguration unterstützt.

\coleng

\texttt{Change the transmitter link mode to MAVLink} - On the radio transmitter (TX), open the ExpressLRS Lua script, select Link Mode, and change the setting from Normal to MAVLink.

\colger

\texttt{Verbindungsmodus des Senders auf MAVLink umstellen} - Öffnen Sie auf dem Funksender (TX) das ExpressLRS-Lua-Skript, wählen Sie Link Mode und ändern Sie die Einstellung von Normal zu MAVLink.

\coleng

\texttt{Enable telemetry via WiFi} - On the radio transmitter (TX), open the ExpressLRS Lua script and select Backpack $\longrightarrow$ Telemetry $\longrightarrow$ WiFi. This automatically configures the TX Backpack, including the UDP port assignment of 14550. If the TX Backpack is not connected to a home WiFi network, it creates a dedicated access point with a name similar to \verb!ExpressLRS TX Backpack XXXXXX! and the default password \verb!expresslrs!. Devices connected to this access point can receive the telemetry data via the assigned UDP port. Alternatively, if the TX Backpack is connected to a home WiFi network, devices on the same network can receive the telemetry data via this port.

\colger

\texttt{Telemetrie über WLAN aktivieren} - Öffnen Sie auf dem Funksender (TX) das ExpressLRS-Lua-Skript und wählen Sie Backpack $\longrightarrow$ Telemetry $\longrightarrow$ WiFi. Dadurch wird der TX Backpack automatisch konfiguriert. Dies schließt die Zuweisung des UDP-Ports 14550 ein. Wenn der TX Backpack nicht mit einem WLAN-Heimnetz verbunden ist, erstellt er einen eigenen Zugangspunkt mit einem Namen ähnlich \verb!ExpressLRS TX Backpack XXXXXX! und dem voreingestellten Passwort \verb!expresslrs!. Geräte, die mit diesem Zugangspunkt verbunden sind, können die Telemetriedaten über den zugewiesenen UDP-Port empfangen. Ist der TX Backpack mit einem WLAN-Heimnetz verbunden, können alternativ alle Geräte im selben Netzwerk die Telemetriedaten über diesen Port empfangen.

\colende

\renewcommand{\deutschertitel}{Konfiguration der MAVLink-Telemetrie für ArduPilot}
\renewcommand{\englischertitel}{Configuring MAVLink Telemetry for ArduPilot}
\makrounterabschnitt
\label{AbschnittExpressLRSMavlinkArduPilotKonfiguration}

To enable MAVLink telemetry on a flight controller running ArduPilot, first identify the UART port to which the ExpressLRS receiver is connected and determine the corresponding ArduPilot \verb!SERIALx! instance. Then navigate to Config $\longrightarrow$ Full Parameter List and configure the following parameters, where \verb!x! denotes the corresponding serial interface: \verb!SERIALx_PROTOCOL=2!, \verb!SERIALx_BAUD=460!, and \verb!RSSI_TYPE=5!.

\colger

Um die MAVLink-Telemetrie auf einem Flugcontroller mit ArduPilot zu aktivieren, muss zunächst der UART-Anschluss ermittelt werden, mit dem der ExpressLRS-Empfänger verbunden ist. Anschließend ist die zugehörige \verb!SERIALx!-Schnittstelle in ArduPilot zu bestimmen. Öffnen Sie danach Config $\longrightarrow$ Full Parameter List und konfigurieren Sie die folgenden Parameter. Dabei bezeichnet \verb!x! die entsprechende serielle Schnittstelle: \verb!SERIALx_PROTOCOL=2!, \verb!SERIALx_BAUD=460! und \verb!RSSI_TYPE=5!.

\colende

\begin{figure}[htb!]
	\centering
	\includegraphics[width=\linewidth]{ExpressLRS_Mavlink_ArduPilot_Configuration.png}
\caption{Configuration of MAVLink Communication in ArduPilot}
	\label{AbbildungExpressLRSMavlinkArduPilotKonfiguration}
\end{figure}
\FloatBarrier
\colstart

Next, in the Full Parameter List, locate the parameters beginning with \verb!SRx_!, where \verb!x! identifies the telemetry stream associated with the previously configured serial interface. Set all \verb!SRx_*! parameters to 1, except for \verb!SRx_ADSB!, \verb!SRx_PARAMS!, and \verb!SRx_RAW_CTRL!, which should remain set to 0 (see Figure~\ref{AbbildungExpressLRSMavlinkArduPilotKonfiguration}).

\colger

Suchen Sie anschließend in der Full Parameter List nach den Parametern, die mit \verb!SRx_! beginnen. Dabei bezeichnet \verb!x! den Telemetriedatenstrom, der der zuvor konfigurierten seriellen Schnittstelle zugeordnet ist. Setzen Sie alle Parameter \verb!SRx_*! auf den Wert 1. Die Parameter \verb!SRx_ADSB!, \verb!SRx_PARAMS! und \verb!SRx_RAW_CTRL! müssen dagegen auf 0 gesetzt bleiben (siehe Abbildung~\ref{AbbildungExpressLRSMavlinkArduPilotKonfiguration}).

\coleng

Finally, restart the flight controller and verify that the ground-station device is receiving telemetry data. Ground-station applications such as Mission Planner, QGroundControl, and MicoAir Configurator can connect to the TX Backpack via WiFi and receive the telemetry data through the assigned UDP port 14550.

\colger

Starten Sie abschließend den Flugcontroller neu und prüfen Sie, ob das Gerät der Bodenstation Telemetriedaten empfängt. Bodenstationsanwendungen wie Mission Planner, QGroundControl und MicoAir Configurator können sich über WLAN mit dem TX Backpack verbinden und die Telemetriedaten über den zugewiesenen UDP-Port 14550 empfangen.
